# 表格1：A320真实ND五种模式的显示与功能

| 模式 | 显示方式 | 功能与适用阶段 |
|------|---------|--------------|
| **ROSE NAV** | 飞机位于显示器中心，航向朝上，显示完整360°罗盘玫瑰 | 全方位导航监控，显示飞行计划航路、航路点、导航辅助设备。适用于航路巡航阶段 |
| **ROSE ILS** | 在ROSE NAV基础上叠加ILS进近引导信息 | 精密进近引导，显示航向道（LOC）和下滑道（G/S）偏差。适用于CAT I/II/III类精密进近 |
| **ROSE VOR** | 在ROSE NAV基础上叠加VOR导航引导信息 | VOR导航引导，显示航道偏差指示器（CDI），包括航道指针、偏航杆、TO/FROM标志。适用于航路导航与非精密进近 |
| **ARC** | 飞机位于显示器底部中心，显示前方约100°扇形区域 | 最大化前方视野，便于观察前方航路和天气信息。巡航与进近阶段最常用模式 |
| **PLAN** | 真北向上固定方位，以目标航路点为中心 | 查看和修改飞行计划，不显示飞机实时位置。适用于航路规划与审查 |

## 补充说明

1. **颜色标准**：A320 ND采用标准化颜色编码——洋红色（主动飞行计划）、青色（航路/航路点）、绿色（主动航段/航迹）、黄色（飞机符号）、琥珀色（警告）、红色（警报/故障）

2. **量程选择**：所有模式均支持6档量程——10/20/40/80/160/320 NM（海里）

3. **高级功能叠加**：在任何模式下均可叠加显示TCAS交通信息、天气雷达回波、EGPWS地形数据

4. **数据来源**：根据Airbus A320 FCOM（飞行机组操作手册）[1]和AMM（飞机维修手册）[2]的技术规范整理
